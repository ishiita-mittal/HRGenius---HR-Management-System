# HRGenius — Advanced HR Management System

HRGenius is a full-stack Human Resource Management System built as an advanced academic project.

## Technology Stack

### Backend

- Java
- Spring Boot
- Spring Security
- JWT
- Hibernate / JPA
- Maven

### Frontend

- Angular
- TypeScript
- Bootstrap

### Database

- Oracle Database

### Planned Features

- Authentication and Authorization
- Role-Based Access Control
- Employee Management
- Recruitment
- Interview Management
- Onboarding
- Attendance
- Leave Management
- Payroll
- Performance Management
- Document Management
- Notifications
- Audit Logging
- HR Analytics
- API Documentation
- Testing
